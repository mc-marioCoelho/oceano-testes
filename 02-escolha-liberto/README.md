# Teste 02 — Escolhe o teu guia (a inscrição como porta de entrada)

**O que testa:** a ideia do Mário de **apontar a câmara à tábula ansata** para que apareçam os quatro libertos e o visitante escolha o seu guia. A RA é **simulada**: o botão «📷 Apontar à inscrição» faz de conta que a câmara reconheceu a pedra.

**A sequência:**
1. O «scanner» passa pela inscrição.
2. **Os quatro nomes acendem-se** um a um.
3. **As letras perdidas reaparecem a azul** (hipótese de leitura, IRCP 35). Os sobrenomes desconhecidos ficam como **[?]**.
4. **Os quatro libertos surgem** em silhueta, cada um com um atributo: rolo, leme, ânfora de peixe, ânfora de azeite.
5. **Toca num deles** e ele apresenta-se com uma voz de timbre diferente, enquanto o nome acende. Também há «Ouvir os quatro».
6. **«✔ Escolher»:** os outros afastam-se e o escolhido dá as boas-vindas. A escolha fica **guardada no aparelho** (para o resto da visita) e é **registada** no painel «Dados de teste (analytics)».

**Ficheiros:** `index.html`, `style.css`, `app.js` (as falas estão no topo, em `LIBERTOS`) e `guiao.md`.

**Experimentar:** abrir `index.html` no Chrome ou no Edge, ou, com o GitHub Pages ativo, `https://mc-mariocoelho.github.io/oceano-testes/02-escolha-liberto/`.

**O que observar:**
- A sequência de abertura (cerca de 7 s) prende a atenção ou é longa?
- Percebe-se que as letras azuis são uma reconstituição?
- Distinguem-se os quatro (timbres, atributos)?
- Escolher é óbvio?
